DESIGN CONCEPT & GOALS

Redesigning Trimex C@nnect (CCS-MS)

This website serves as a full front-end redesign for the official Trimex C@nnect - College of Computer Studies portal[cite: 1]. The primary objective of this project is to replace outdated layouts and broken media elements[cite: 1] with a high-performance, visually engaging UI catered specifically to IT and Computer Science students.

Bento Layout Architecture

Organizes all 14 CCS-MS systems into clean, searchable dashboard cards for intuitive navigation across academic tools, cyber ranges, and student portals.

KonKon Mascot Integration

Features KonKon, the official CCS mascot, to create an appealing identity tailored for Computer Studies students.

Built using HTML5, Tailwind CSS, FontAwesome, and JavaScript.
